# Exam Duty Scheduler

## About the Project

Exam Duty Scheduler is a web-based application developed using HTML, CSS, and JavaScript. It helps organize examination duties by assigning teachers to examination rooms and managing exam schedules.

## Features

* Add and manage examination dates.
* Add and manage examination rooms.
* Add and manage teacher details.
* Automatically generate examination duty schedules.
* Assign invigilators to rooms.
* Assign relievers for each exam day.
* View duty statistics for teachers.
* Print the generated schedule.
* Save data in the browser using Local Storage.

## Technologies Used

* HTML
* CSS
* JavaScript
* Browser Local Storage

## How to Run

1. Download or clone the repository.
2. Open the project folder.
3. Open `exam_duty_scheduler (1).html` in your web browser.
4. Add exam dates, rooms, and teacher details.
5. Generate and review the examination duty schedule.

## Project Structure

* `index.html` – Main webpage for the modular version.
* `styles.css` – Styling for the application.
* `data.js` – Data management.
* `scheduler.js` – Duty scheduling logic.
* `ui.js` – User interface functions.
* `utils.js` – Utility functions.
* `exam_duty_scheduler (1).html` – Standalone version of the application.
* `DEV.md` – Development guide.
* `FEATURES.md` – Project features.
* `.gitignore` – Specifies files Git should ignore.

**Note:** The standalone HTML file is the simplest option to run. The modular version may require correct JavaScript file paths and imports.
